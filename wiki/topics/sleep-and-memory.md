# 睡眠與記憶鞏固

Memory consolidation 指學過的資訊隨時間變得較能保留的過程。兩項線上實驗中，夜間睡眠組隔約 12 小時的字詞配對保留表現高於日間清醒組；此比較同時涉及不同測試時間（[Guttesen 等人，2025](../papers/guttesen-2025-overnight-memory.md)，第 5、8 頁）。

保留舊資訊不等同學習新資訊：新字詞配對的立即表現在第一項實驗無顯著組間差異，第二項則為清醒組較高。睡眠組保留與新學習的正相關僅出現在額外探索性分析，仍需確認（[Guttesen 等人，2025](../papers/guttesen-2025-overnight-memory.md)，第 5、8、10–11 頁）。
